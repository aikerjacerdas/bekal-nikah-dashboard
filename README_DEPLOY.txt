BEKAL NIKAH | WEBSITE DASHBOARD UNTUK CLOUDFLARE PAGES
====================================================

ISI PAKET
- index.html : aplikasi dashboard utama.
- content.json : data konten terstruktur yang disertakan bersama paket.
- main/ : 4 dokumen utama PDF.
- bonus/ : 10 dokumen bonus (PDF, XLSX, DOCX).

PENGATURAN CLOUDFLARE PAGES
1. Hubungkan repository GitHub: aikerjacerdas/bekal-nikah-dashboard.
2. Production branch: main.
3. Framework preset: None.
4. Build command: kosongkan.
5. Build output directory: .
6. Root directory (advanced): kosongkan.
7. Setelah seluruh file paket masuk ke root repository, baru klik Save and Deploy / Deploy.

PENTING: UPLOAD STRUKTUR FOLDER
Pastikan index.html dan content.json berada langsung di root repository.
Pastikan folder main dan bonus berada sejajar dengan index.html.
Jangan mengunggah folder pembungkus BEKAL_NIKAH_Cloudflare_Pages sehingga file aplikasi berada satu tingkat terlalu dalam.

DATA DAN PRIVASI
- Catatan yang diisi pengguna disimpan di localStorage browser pada perangkat yang digunakan.
- Data tidak dikirim ke server dan tidak tersinkron otomatis antarperangkat.
- Pengguna perlu membuat backup JSON sebelum berpindah perangkat atau membersihkan data browser.
- Hindari mengisi kata sandi, PIN, nomor rekening lengkap, atau data sangat sensitif ke kolom catatan.
- Dashboard ini belum memiliki login atau kontrol akses pembeli. URL Pages dan file dokumen yang dihosting bersifat publik bagi siapa pun yang memperoleh tautannya. Tautan dapat diteruskan. Jangan menganggap URL sebagai sistem lisensi atau proteksi produk.

CATATAN PENGGUNAAN
Dashboard ini merupakan sarana refleksi dan percakapan calon pasangan. Dashboard bukan tes kecocokan, penilaian kelayakan menikah, nasihat medis, atau dokumen hukum yang mengikat.
